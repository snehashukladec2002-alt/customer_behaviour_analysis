# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

The **Customer Shopping Behavior Analysis** project focuses on analyzing customer purchasing patterns, shopping preferences, spending behavior, and subscription trends using data analytics tools.

The objective is to extract meaningful insights from customer shopping data and present them through SQL analysis and an interactive Power BI dashboard.

## 🎯 Project Objectives

- Analyze purchasing behavior across different customer demographics.
- Compare revenue generated by male and female customers.
- Identify the impact of discounts on customer purchases.
- Analyze customer subscription patterns.
- Identify top-rated and most-purchased products.
- Understand purchasing trends across different age groups.
- Create meaningful visualizations using Power BI.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning and preprocessing
- **Google Colab:** Python environment
- **MySQL:** Database management and SQL analysis
- **Power BI:** Interactive dashboard and data visualization

## 📊 Dataset Description

The dataset contains customer shopping information, including:

- Customer ID
- Age and Gender
- Item Purchased
- Category
- Purchase Amount
- Review Rating
- Shipping Type
- Discount Applied
- Subscription Status
- Previous Purchases
- Age Group

## 🔍 SQL Analysis

The project includes 10 SQL analysis questions:

1. Revenue generated by male and female customers.
2. Customers who used discounts and spent above the average purchase amount.
3. Top 5 products based on average review ratings.
4. Average purchase amount by shipping type.
5. Average spending and total revenue by subscription status.
6. Top 5 products with the highest discount percentage.
7. Customer segmentation into New, Returning, and Loyal customers.
8. Top 3 most-purchased products in each category.
9. Subscription behavior of repeat buyers.
10. Revenue contribution by age group.

## 📈 Power BI Dashboard

An interactive Power BI dashboard is being developed to visualize customer shopping insights.

The dashboard aims to present:
- Customer demographics
- Revenue analysis
- Product performance
- Discount trends
- Subscription analysis
- Age-group purchasing behavior

- Connecting MySQL databases with Power BI.
- Creating interactive dashboards and visual reports.
